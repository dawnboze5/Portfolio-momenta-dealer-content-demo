# Momenta AI赋能经销商智驾素材内容与数据管理平台-Demo版

## 项目背景

希望通过数字化平台的⽅式提升经销商⻔店矩阵号中智驾内容的多样化传播与⾼效管理。以⾼质量、易于使⽤的智驾内容为核⼼，赋能经销商进⾏传播，并通过数据追踪与分析，实现传播效果的可量化评估与优化。

## 已完成探索成果

- **权限细化与隔离**：控制经销商和市场部的权限差异。经销商只能看到⾃⼰以往上传的视频数据，⽆法看到整体数据汇总及数据分析；市场部拥有整个数据库和分析结果的查看及编辑权限。
- **平台功能模块优化与数据看板升级**：完成两大功能模块设计——内容中心、数据看板。
  - **内容中心**：可跳转至公司⻜书资料库，便于经销商查找资料并下载。
  - **数据看板**：实现了⾃动识别、上传链接、周报展⽰、多维分析功能，使数据录⼊⼯作量降低、数据展⽰更清晰。
