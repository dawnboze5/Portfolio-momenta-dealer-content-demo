# 智驾内容赋能与数据管理平台 Demo

这是一个静态网页演示项目，可通过 GitHub Pages 发布。

## 发布步骤

1. 在 GitHub 新建一个仓库，例如 `driving-content-demo`。
2. 将 `index.html` 和 `README.md` 上传到仓库根目录。
3. 进入仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/(root)`，点击 **Save**。
6. 等待部署完成后，GitHub Pages 会显示公开网址，通常格式为 `https://你的用户名.github.io/仓库名/`。

## 说明

此项目为静态前端 Demo。页面中的演示数据、模拟识别和前端身份切换不等同于真实的后端认证、数据库或 OCR 服务。请勿上传真实业务数据、账号密码或敏感信息。
